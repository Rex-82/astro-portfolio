# English and Italian content

The site uses Astro's native i18n routing. English URLs remain at the root; Italian pages live under `/it/`. Shared page templates are in `src/templates/` and UI copy is in `src/i18n/index.ts`. Add a matching key to both dictionaries when adding a string.

Blog Markdown lives in `src/content/blog/`. Existing English files keep their current paths and IDs. Every post declares `lang` and a stable `translationKey`. For a translation, create `src/content/blog/it/<italian-slug>/index.md`, set `lang: it`, and copy the original `translationKey`. The public Italian URL is `/it/blog/<italian-slug>/`. Publish with `draft: false`. Do not copy the English body into an Italian file: untranslated posts appear once in Italian lists with their original title, an “In inglese” label, and a link to their English URL. Italian article routes and RSS items exist only for published Italian Markdown.

Generated cover artwork uses `translationKey` as its seed. If a post has `coverImage`, the translation can use its own image. `noindex` posts remain accessible but stay out of the sitemap and feeds.

Check with `node --test tests/i18n-blog.test.mjs`, `pnpm build`, and `git diff --check`. Also inspect both languages in the browser at 320, 390, 641 and 1280 px after changing shared UI.
